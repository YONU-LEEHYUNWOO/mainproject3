# AI 케어비서 서비스 (부모용 + 자식용 서비스 통합 기획서)

---

# 1. 서비스 개요

AI 케어비서는 1인 노인가구 증가 시대에 맞춰

노인의 일상 전체를 관리하고 안전을 보조하는 부모용 서비스와,

부모님의 일정·건강·위치·생활 패턴을 확인하고 관리하는 자식용(보호자) 서비스로 구성된 양방향 케어 플랫폼이다.

부모 앱(AI 케어비서)은 하루 전체의 일정을 능동적으로 챙기는 AI 기반 생활 케어 서비스이며,

자식 앱(AI 케어 매니저)은 부모님의 일정을 등록하고 하루 상태를 실시간으로 확인하며,

필요한 행동 지침을 부모 앱으로 전달하는 관리 서비스이다.

---

# 2. 서비스 제공 목적

부모용 서비스

- 노인의 하루 전체 루틴을 AI가 먼저 챙겨주는 능동형 케어 제공
- 이동, 병원, 일정, 식사, 장보기 등 실제 생활을 지원
- 고립감 방지 및 정서적 보조
- 무활동 감지 등 안전 기반 서비스로 보호자 안심 제공

자식용 서비스

- 부모님의 일정 및 건강·생활 패턴 데이터를 통해 지속적인 케어 참여
- 부모님 일정 관리 및 예약 정보 입력
- 실시간 상태 확인 및 위험 알림 수신
- 부모-자식 간 상호 연결 중심의 케어 구조 형성

---

# 3. 서비스 구조 요약 (Dual App Structure)

부모용 앱(AI 케어비서)

- 노인 사용자 중심
- 음성·버튼 기반 인터페이스
- AI가 먼저 제안하는 능동형 케어
- 이동·식사·병원·휴식·안전 전반 관리

자식용 앱(AI 케어 매니저)

- 보호자 중심
- 부모님의 일정 등록, 병원 정보 입력
- 부모의 하루 행동 패턴 실시간 확인
- 리포트 분석 및 위험 상황 모니터링
- 필요 시 부모 앱에 행동 지시 전달

---

# 4. 부모용 서비스 주요 기능

아침 케어

- 오늘 일정 확인
- 병원/중요 일정 안내
- 예/아니오에 따라 이동 준비 또는 대안 제안

병원 이동 케어

- 자동 이동 시간 계산
- 날씨·교통·준비물 안내
- 택시/대중교통 추천
- 병원 도착 체크 및 대기 정보 제공

진료 후 케어

- 귀가 여부 안내
- 귀가 선택 시 이동 경로 안내
- 귀가하지 않는 경우 장보기·식사 등 행동 제안

하루 루틴 케어

- 장보기·식사·산책 등 일상 제안
- 사용자 패턴 기반 자동 추천
- 약 복용 알림
- 정서 기반 대화 및 보조

휴식/안전 케어

- 휴식 모드 → 자동 무활동 감지 활성화
- 1차 사용자 확인
- 미응답 시 보호자에게 알림 발송

하루 마무리

- 하루 요약
- 내일 일정 예고
- 취침 모드 자동 실행

---

# 5. 자식용 서비스 주요 기능

부모 일정 관리

- 병원 예약 입력
- 위치 등록
- 반복 일정 설정
- 약 복용 시간 등록
- 운동·산책 계획 입력

부모 상태 모니터링

- 현재 위치
- 이동 중 / 대기 중 / 휴식 중 / 취침 중
- 오늘의 행동 기록
- 위험 알림 수신
- 이동 반경·활동량·정서 변화 확인

AI 리포트 분석

- 병원 방문 패턴
- 이동 반경 변화
- 활동량 감소·증가 분석
- 정서적 변화 요약
- 외출 패턴 변화 기반 위험 감지

부모에게 지시/메시지 전송

- 산책·식사·장보기 요청
- 음성/텍스트 메시지 전송
- 부모님 앱에서 “큰 글씨 + 음성”으로 재구성되어 전달

보호자 계정 관리

- 보호자 초대
- 리포트 주기 설정
- 응급 알림 분배
- 여러 보호자가 함께 모니터링 가능

---

# 6. 부모-자식 서비스 간 데이터 흐름

자식 앱

→ 일정/지시 입력

→ AI 엔진이 부모 맞춤 케어 계획 생성

→ 부모 앱 실행

→ 부모의 행동/위치/상태 수집

→ AI 엔진이 하루 요약 및 분석

→ 자식 앱으로 리포트 전달

이 구조를 통해 부모의 생활과 자식의 관리가 상호 순환되며

안전성과 케어 품질이 높아지는 구조를 형성한다.

---

# 7. 기술 구조

AI 대화 엔진

- 노인 맞춤형 언어 처리
- 일정 자동 생성 및 추천
- 패턴 기반 행동 예측
- 정서 분석 기반 대화 제공

스마트폰 센싱

- GPS 기반 이동정보
- 장시간 무활동 감지
- 화면 및 터치 활동 분석
- 간단한 속도·위치 변화 감지

추천 시스템

- 식사·장보기·산책·휴식·외출 등 맞춤 추천
- 과거 행동 데이터 기반
- 보호자 입력 데이터 기반 자동 조정

외부 API 연동

- 택시 호출 API
- 지도/교통/버스 정보 API
- 날씨 API
- 온라인 장보기 API
- 병원 위치·예약 API

고령자용 UX

- 큰 글씨·큰 버튼
- 음성 중심
- 단계 최소화
- 예/아니오 중심 선택지

# 8. 서비스의 차별화 포인트

AI가 먼저 제안하는 능동 케어

일정 → 이동 → 병원 → 행동 추천 → 휴식 → 안전 감지까지

하루 전체를 관리하는 AI 비서 구조

가족 중심 연결 강화

단순 돌봄앱이 아닌

가족이 함께 유지하는 “패밀리 케어 서비스” 구조

이원화된 앱 구조

부모용은 케어·안전·일상 중심

자식용은 관리·모니터링·분석 중심

행동 패턴 기반 고독사 예방 기술

외출 감소, 활동량 감소, 정서 변화 등을 자동 감지

스마트폰 기반만으로 이용 가능

추가 장치 없이 서비스 이용 가능

보호자 참여를 필수 요소로

정기 연락 인증·리포트 수신 시스템으로

부모-자식 관계 유지 기능 강화
