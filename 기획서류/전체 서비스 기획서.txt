# AI 케어비서 서비스 (부모용 + 자식용 서비스 통합 기획서) - MVP v1.0

---

# 1. 서비스 개요

AI 케어비서는 1인 노인가구 증가 시대에 맞춰

노인의 일상 생활을 관리하고 안전을 보조하는 부모용 서비스와,

부모님의 일정·건강·위치·생활 패턴을 확인하고 관리하는 자식용(보호자) 서비스로 구성된 양방향 케어 플랫폼이다.

부모 모드(AI 케어비서)는 AI 기반 음성/채팅 인터페이스로 일정과 약 복용을 쉽게 관리하는 생활 케어 서비스이며,

자녀 모드(AI 케어 매니저)는 부모님의 일정을 등록하고 하루 상태를 실시간으로 확인하며,

무활동 감지 및 알림을 통해 안전을 관리하는 모니터링 서비스이다.

---

# 2. 서비스 제공 목적

부모용 서비스

- AI 음성/채팅 인터페이스로 쉬운 일정 및 약 관리
- 위치 기반 장소 검색 및 길찾기 지원
- AI 맞춤 생활 가이드 (이동 분석, 준비물 안내)
- 고립감 방지 및 정서적 보조
- 무활동 감지 등 안전 기반 서비스로 보호자 안심 제공
- 큰 버튼, 음성 중심의 노인 친화적 UX

자식용 서비스

- 부모님의 일정 및 약 복용 데이터 실시간 확인
- 부모님 일정 관리 및 약 알림 설정 (보호자 권한)
- 실시간 무활동 상태 모니터링 (10초 주기)
- 위험 알림 자동 수신
- 부모-자식 간 상호 연결 중심의 케어 구조 형성

---

# 3. 서비스 구조 요약 (Dual Mode Structure)

부모 모드 (AI 케어비서)

- 노인 사용자 중심
- 음성·버튼 기반 대형 UI
- AI 채팅으로 일정/약 관리
- 위치 기반 길찾기 및 장소 검색
- 이거부탁해 (자녀에게 요청)
- 접근성 설정 (큰 글씨, 음성 안내)

자녀 모드 (AI 케어 매니저)

- 보호자 중심 대시보드
- 부모님의 일정 등록 및 약 알림 설정
- 실시간 상태 확인 (위치, 무활동, 일정, 약)
- 알림 수신 및 관리
- 이거부탁해 응답 및 관리
- AI 채팅 (부모님 케어 상담)

# 4. 부모용 서비스 주요 기능 (현재 구현)

## 홈 대시보드

- 오늘 일정 요약 (완료/미완료 현황)
- 오늘 복용할 약 목록
- **AI 능동형 케어 메시지** (실시간 생성)
  - AI가 먼저 현재 상황을 파악하고 메시지 전송
  - 일정 완료 상황 인식 및 격려 ("오전 일정을 잘 마치셨으니 편안한 오후 보내세요")
  - 다음 행동 예고 ("저녁 약 복용 시간 전에 미리 알려드릴게요")
  - 시간대, 일정, 약 복용 상태를 종합 분석
  - 다정하고 공손한 톤의 맞춤형 메시지
- 큰 음성 인식 버튼 (텍스트 포함, 그라데이션 디자인)
- 실시간 알림 센터

## AI 음성/채팅 케어

- **전체 서비스 음성 인식 지원 (Web Speech API)**
  - 홈: AI 관리 버튼 (큰 음성 버튼)
  - Chat: 대화 입력
  - 이거부탁해: 요청 내용 + 자주 사는 물건
  - 일정 등록: 제목, 설명
  - 약 등록: 약 이름, 용법/용량, 처방전
  - 위치 검색: 장소명 (자동 검색 실행)
- 일정 자동 추출 및 등록
- 주변 장소 검색 (약국, 병원 등)
- 장소 좌표 자동 검색 (카카오 로컬 API 연동)
- 보호자 호출 기능
- 텍스트 입력 지원 (키보드 + 음성 병행)
- 장소 선택 모달 (SEARCH_LOCATION 액션)

## 일정 관리

- 일정 등록/수정/삭제
  - **제목, 설명 음성 입력 지원**
  - 각 입력창에 마이크 버튼 배치
- 달력 뷰 (월별/일별)
- 일정 완료 체크
- 우선순위 설정 (낮음/보통/높음)
- 카테고리 분류 (병원, 약국, 식사, 은행, 관공서 등)
- AI 맞춤 생활 가이드 
  - 이동 시간 계산 (카카오 모빌리티 API)
  - 추천 출발 시간 제안
  - 준비물 안내 (AI 생성)
  - 거리 및 택시비 표시
- 카카오 길찾기 연동
- 장소 좌표 자동 검색 및 업데이트

## 약 복용 관리

- 약 알림 등록/수정/삭제
  - **약 이름, 용법/용량, 처방전 정보 음성 입력 지원**
  - 복잡한 약 이름도 음성으로 쉽게 입력
  - 각 입력창에 마이크 버튼 배치
- 시간대별 복용 설정 (최대 4회/일)
- 빠른 설정 (아침식후 08:00, 점심식후 12:30, 저녁식후 18:30)
- 복용 완료 체크 (시간별 개별 체크)
- 복용 미루기 (10분/30분/1시간)
- 복용 건너뛰기
  - 사유 선택: 몸이 안 좋아서/약이 없어서/깜빡했어요/기타
  - 상세 사유 입력 가능
  - 보호자에게 자동 알림 전송
- 재고 관리
  - 현재 재고 수량
  - 경고 재고 기준 설정 (기본: 5개)
  - 재고 부족 시 보호자 자동 알림
- 처방전 정보 텍스트 저장 (음성 입력 가능)
- 복용 기간 설정 (시작일, 종료일)

## 위치 기반 서비스

- 현재 위치 자동 추적 (GPS, 1분 주기)
- 주변 장소 검색 (카카오 지도 API)
  - **음성으로 장소명 검색 가능**
  - 음성 인식 후 자동 검색 실행
  - 마이크 버튼 클릭 → 말하기 → 자동 검색
- 카테고리별 검색 (약국, 병원, 은행, 관공서, 카페 등)
- 길찾기 및 경로 안내 (카카오 길찾기)
- 즐겨찾기 장소 등록/관리
- 주 장소 설정 (is_primary)
- 일정과 연동된 길안내
- 위치 공유 설정 (설정에서 On/Off)
- 위치 이력 DB 저장

## 건강 기록

- 건강 상태 기록
- 병원 방문 기록
- 건강 데이터 조회

## 이거부탁해

- 자녀에게 요청 전송 (최대 500자)
- **음성 인식으로 요청 내용 입력 가능**
  - 큰 음성 인식 버튼 (그라데이션 디자인)
  - 음성 인식 중 시각적 피드백 (빨간색 애니메이션)
- 텍스트 직접 입력 지원 (큰 입력창)
- **자주 사는 물건 관리**
  - 자주 사는 물건 목록 등록/삭제
  - 목록에서 한 번에 선택하여 전송
  - 큰 버튼과 텍스트로 쉬운 접근
- **마트 찾기 바로가기**
  - 즐겨찾기 연동 (등록된 마트로 바로 길찾기)
  - 미등록 시 주변 마트 검색
  - 전체 화면 버튼으로 쉬운 접근
- 요청 목록 확인 (완료/미완료 필터)
- 완료 상태 실시간 확인
- **노인 친화적 UI**
  - 큰 버튼 (최소 py-4, px-6)
  - 큰 텍스트 (text-lg ~ text-2xl)
  - 명확한 아이콘 크기 (24px ~ 32px)
  - 그라데이션 및 그림자 효과
  - 명확한 색상 구분

## 설정

- 알림 설정 (일정 알림, 약 알림 개별 On/Off)
- 알림 시간 설정 (일정: 15분 전, 약: 분 단위 설정)
- 위치 공유 설정 (On/Off)
- 프로필 관리 (이름, 전화번호, 이메일)
- 접근성 설정 (큰 글씨, 음성 안내)
- 보호자 관리
- 즐겨찾기 장소 관리

# 5. 자식용 서비스 주요 기능 (현재 구현)

## 대시보드

- 부모님 오늘 일정 현황 (완료/미완료 건수)
- 부모님 약 복용 현황 표시
- 실시간 무활동 상태 모니터링
  - 정상 (초록색)
  - 경고 (노란색, 임계값 초과)
  - 위험 (빨간색, 위험 임계값 초과)
- **AI 능동형 케어 센터**
  - 부모님께 전송된 AI 케어 메시지 실시간 확인
  - AI가 부모님 상황을 분석한 메시지 내용 조회
  - 일정 완료, 약 복용 등 상태 기반 메시지 생성 현황
- 실시간 알림 센터 (미읽음 강조)
- 30초 자동 데이터 갱신
- 무활동 상태 10초 간격 실시간 폴링

## 부모 일정 관리

- 부모님 일정 등록/수정/삭제 (보호자 권한)
- 장소 검색 및 좌표 자동 등록 (카카오 지도 API)
- 일정 완료 상태 확인 및 토글
- 우선순위 및 카테고리 설정
- 달력 뷰 제공 (월별/일별)
- 일정별 AI 맞춤 가이드 확인
- 보호자 권한 검증 (Guardian 테이블)

## 부모 약 관리

- 부모님 약 알림 등록/수정/삭제 (보호자 권한)
- 복용 시간대 설정 (최대 4회/일)
- 아침/점심/저녁 빠른 설정
- 복용 기록 확인
- 건너뛰기 로그 상세 확인
  - 건너뛴 시간
  - 건너뛴 사유
  - 상세 내용
- 재고 관리 및 경고 확인
- 처방전 정보 관리
- 보호자 권한 검증 (Guardian 테이블)

## 부모 위치 모니터링

- 실시간 위치 확인 (카카오 지도)
- 부모님 위치 중심 지도 표시
- 부모님 위치 기반 주변 검색
- 즐겨찾기 장소 등록/관리
- 경로 안내 제공

## 무활동 감지 모니터링

- 실시간 무활동 상태 표시 (정상/경고/위험)
- 마지막 활동 시간 확인
- 무활동 시간 실시간 표시
- 무활동 임계값 설정 (기본: 경고 30분, 위험 60분)
- 자동 알림 발송 (무활동 감지 시)
- 무활동 이력 조회
- 무활동 통계

## 알림 관리

- 부모님 관련 실시간 알림 수신
- 약 건너뛰기 알림 (약 이름, 시간, 사유 포함)
- 무활동 경고 알림
- 재고 부족 알림
- 읽음/미읽음 상태 관리
- 알림 유형별 필터링 및 검색
- 최근 20개 기본 표시

## 이거부탁해 관리

- 부모님 요청 실시간 확인
- 요청 완료 처리
- 요청 이력 관리
- 완료/미완료 필터

## AI 채팅

- 부모님 케어 관련 AI 상담
- 일정/약 관리 조언
- 장소 검색 지원
- 음성 인식 지원

## 보호자 관리

- 보호자 정보 등록/수정/삭제
- 관리 대상 사용자 확인
- 보호자 관계 설정
  - 관계 타입 (parent, spouse, child, sibling, relative, friend, caregiver, other)
  - 주 보호자 설정 (is_primary)
  - 응급 연락처 설정 (emergency_contact)
  - 알림 수신 설정 (notification_enabled)
  - 접근 권한 (view, edit, full)

## 설정

- 프로필 관리
- 알림 설정
- 접근 권한 설정

# 6. 부모-자식 서비스 간 데이터 흐름 (현재 구현)

자식 앱에서 일정/약 등록

→ DB에 저장 (보호자 권한 검증)

→ 부모 앱에서 조회 및 알림 수신

→ 부모의 행동 데이터 수집 (일정 완료, 약 복용, 터치 활동)

→ 부모의 위치 데이터 수집 (GPS, 1분 주기)

→ 무활동 감지 엔진 (실시간 분석)

→ 자식 앱으로 알림 전달 (약 건너뛰기, 무활동 경고, 재고 부족)

→ 자식 앱에서 확인 및 조치

이 구조를 통해 부모의 생활과 자식의 관리가 실시간으로 연동되며

안전성과 케어 품질이 높아지는 구조를 형성한다.

# 7. 기술 구조 (현재 구현)

## AI 대화 엔진 (Google Gemini 2.5 Flash)

- 노인 맞춤형 언어 처리 (공손하고 다정한 말투)
- 일정 자동 추출 (날짜, 시간, 장소)
- 텍스트에서 개체 정보 추출 (dates, times, locations, medicines)
- 의도 분석 (schedule, health, medicine, search_place, emergency 등)
- 액션 생성
  - ADD_TASK: 일정 직접 등록
  - SEARCH_LOCATION: 장소 검색 팝업 (일정 등록 전)
  - SEARCH, SEARCH_STORE: 주변 검색 및 지도 이동
  - CALL_GUARDIAN: 보호자 호출
- AI 맞춤 생활 가이드 생성
  - 이동 시간 및 추천 출발 시간 계산
  - 일정 유형별 준비물 안내 (병원: 신분증/진료카드, 은행: 도장/신분증 등)
  - 다정한 격려 메시지
- **능동형 케어 메시지 생성** (실시간 상황 분석)
  - 현재 시간대 분석 (아침/점심/저녁/밤)
  - 일정 완료 상태 확인 및 격려 메시지 생성
  - 다음 일정/약 복용 예고 메시지
  - 오늘 남은 할 일 안내
  - 무활동 시간 확인 및 활동 격려
  - 상황에 맞는 다정하고 공손한 톤 자동 생성
  - 예시:
    - "오전 일정을 잘 마치셨으니 편안한 오후 보내세요"
    - "저녁 약 복용 시간 전에 미리 알려드릴게요"
    - "오늘 병원 방문 일정이 있으시네요. 준비는 잘 되셨나요?"
- 긴급 상황 감지 (키워드 기반)

## 위치 추적 시스템

- GPS 기반 실시간 위치 추적 (1분 주기, 부모 모드만)
- 위치 이력 DB 저장
- 카카오 Geocoder로 주소 변환
- 위치 공유 설정 지원 (On/Off)
- 타임아웃 30초, 캐시 60초 (배터리 절약)
- 무활동 감지를 위한 터치 활동 추적

## 카카오 API 연동

- 카카오 지도 API (지도 표시, 마커, 인포윈도우)
- 카카오 로컬 API (키워드 검색, 좌표 검색)
  - 키워드 검색: 약국, 병원 등
  - 장소 좌표 자동 검색 (location → latitude, longitude)
- 카카오 모빌리티 API (경로 계산)
  - 도보/차량 경로
  - 소요 시간, 거리, 택시비
  - 경로 좌표 (Polyline)

## 무활동 감지 시스템

- 마지막 활동 시간 추적 (터치, 페이지 이동, 일정/약 체크)
- 실시간 무활동 상태 판단 (정상/경고/위험)
- 설정 가능한 임계값
  - 경고: 기본 30분
  - 위험: 기본 60분
- 자동 알림 발송 (무활동 감지 시)
- 무활동 이력 및 통계

# 8. 서비스의 차별화 포인트 (MVP)

## AI 기반 음성 인터페이스 (전면 확대)

- **전체 서비스 음성 인식 지원** (시니어 앱 트렌드 반영)
  - 홈, Chat, 이거부탁해, 일정, 약, 위치 검색 등 모든 입력창
  - 키보드 없이도 모든 기능 사용 가능
  - 복잡한 약 이름, 장소명도 음성으로 쉽게 입력
- 음성으로 일정 추가, 장소 검색
- 노인도 쉽게 사용 가능한 대형 버튼 UX
- AI가 액션을 판단하고 프론트엔드가 실행하는 Agent 구조
- 음성 인식 중 명확한 시각적 피드백 (빨간색 애니메이션)

## AI 능동형 케어 (차별화 핵심)

- **AI가 먼저** 사용자 상황을 파악하고 메시지 전송
- 일정 완료 상태 인식 및 자동 격려
- 다음 행동 예고 (약 복용, 외출 준비 등)
- 시간대별 맞춤 메시지 (아침/점심/저녁)
- 수동 응답이 아닌 **능동적 케어** 제공
- 사용자가 요청하지 않아도 AI가 챙김
- 예시:
  - "오전 일정을 잘 마치셨으니 편안한 오후 보내세요"
  - "저녁 약 복용 시간 전에 미리 알려드릴게요"

## 실시간 부모-자녀 연동

- 자녀가 등록한 일정을 부모가 즉시 확인
- 부모의 약 건너뛰기를 자녀가 실시간 알림 수신
- 무활동 감지 시 자동 알림 (10초 주기 폴링)
- 재고 부족 시 자동 알림

## 통합 모드 설계

- 하나의 앱에서 부모/자녀 모드 전환
- 동일한 계정으로 양쪽 모드 사용 가능 (MVP)
- 향후 별도 계정 및 보호자 연결 강화 가능

## 보호자 권한 시스템

- 자녀는 부모의 데이터를 조회/수정 가능 (Guardian 관계 기반)
- 부모는 본인 데이터만 관리
- 약/일정 삭제/수정 시 보호자 권한 자동 검증

## 무활동 감지

- 실시간 모니터링 (10초 주기)
- 자동 알림 발송
- 무활동 이력 및 통계
- 설정 가능한 임계값

## 스마트폰 기반만으로 이용 가능

- 추가 장치 없이 서비스 이용 가능
- GPS, 터치 활동만으로 안전 감지
- 웹 기반으로 설치 없이 사용 가능

## 자동 좌표 검색

- 장소명만 입력해도 좌표 자동 검색
- AI 일정 추가 시 좌표 자동 추가
- 기존 일정 분석 시 좌표 없으면 자동 검색 및 업데이트

# 9. 현재 구현된 기능 흐름 요약

## 부모 모드

홈 화면에서 큰 음성 인식 버튼 클릭

→ 음성 인식 ("내일 3시에 강남병원 가야해")

→ Chat 페이지로 이동 및 자동 전송

→ AI 분석 (일정 정보 추출)

→ 장소 좌표 자동 검색 (카카오 로컬 API)

→ 일정 자동 등록

→ AI 응답 표시 ("✅ 일정이 등록되었습니다")

일정 확인 → AI 맞춤 생활 가이드 조회

→ 이동 시간 계산, 출발 시간 추천, 준비물 안내

**AI 능동형 케어 메시지 수신**

→ 일정 완료 후 격려 메시지 ("오전 일정을 잘 마치셨으니...")

→ 다음 행동 예고 ("저녁 약 복용 시간 전에...")

→ 홈 대시보드에 실시간 표시

약 복용 시간 → 알림 수신 → 복용 완료 체크

위치 자동 수집 (1분 주기) → 무활동 감지

## 자녀 모드

대시보드에서 부모님 상태 확인

→ 무활동 상태 실시간 표시 (10초 주기)

→ 일정/약 등록 및 관리 (보호자 권한)

→ 알림 수신 (약 건너뛰기, 무활동 경고, 재고 부족)

→ 알림 확인 및 조치

→ 이거부탁해 응답

# 10. 향후 발전 방향 (고도화 로드맵)

## 능동 케어 강화 (현재 기본 기능 구현 완료)

**현재 구현된 능동 케어**:
- ✅ AI가 상황을 파악하고 먼저 메시지 전송
- ✅ 일정 완료 상태 인식 및 격려
- ✅ 다음 행동 예고 (약 복용 등)
- ✅ 시간대별 맞춤 메시지

**향후 고도화 계획**:
- 시간대별 **자동 푸시 알림** (아침 인사, 약 복용 리마인드, 취침 안내)
- AI가 먼저 제안하는 **하루 전체 루틴 관리**
  - 아침 일정 확인 → 이동 준비 → 병원 방문 → 진료 후 행동 추천 → 귀가/장보기/식사 → 휴식 → 하루 마무리
- 일정 시간 기반 **자동 알림** (출발 시간, 도착 확인)
- GPS 기반 **도착 자동 감지**
- **날씨 정보 연동** (추가 구현 권장)
  - 외출 전 날씨 안내 ("오늘 비가 올 예정이니 우산 챙기세요")
  - 기온에 따른 옷차림 제안
  - 미세먼지 나쁨 시 외출 자제 권고

## 하루 흐름 관리

- 일정 → 이동 알림 → 도착 확인 → 다음 일정 안내
- 진료 후 행동 제안 (귀가/장보기/식사)
- 휴식 모드 자동 전환
- 취침 모드 및 야간 무활동 감지 비활성화

## 외부 API 연동 확장

- 택시 호출 API (카카오 T, 우버)
- **날씨 API 연동** (추가 구현 권장)
  - 기상청 공공 데이터 API 활용
  - 현재 위치 기반 실시간 날씨 정보
  - 홈 대시보드에 오늘의 날씨 표시
  - 외출 전 날씨 안내 (AI 능동형 케어 메시지에 포함)
  - 기온, 강수 확률, 미세먼지 정보
  - 외출 시 우산 챙기기 알림
- 온라인 장보기 API (마켓컬리, 쿠팡)
- 병원 예약 API

| 인터페이스 | 큰 버튼, 음성 중심 | 대시보드 중심 UI |
| 주요 기능 | AI 채팅, 일정·약 관리, 위치 | 모니터링, 알림, 무활동 감지 |
| AI 역할 | 일정 추출, 장소 검색, 가이드 | AI 상담, 조언 |
| 특징 | 음성 인식, 큰 UI, 접근성 | 실시간 모니터링, 알림 |
| 권한 | 본인 데이터만 | 부모 데이터 조회/수정 가능 |

# 13. MVP에서 구현된 핵심 가치

1. **AI 능동형 케어 (차별화 핵심)**: AI가 먼저 상황을 파악하고 메시지를 전송하는 능동적 케어
   - 일정 완료 상태 인식 및 자동 격려
   - 다음 행동 예고 및 안내
   - 시간대별 맞춤 메시지 실시간 생성
   
2. **AI 기반 쉬운 관리**: 음성/채팅으로 일정과 약을 쉽게 관리

3. **실시간 연동**: 부모-자녀 데이터 실시간 동기화

4. **안전 감지**: 무활동 감지 및 자동 알림

5. **위치 기반 서비스**: 장소 검색, 길찾기, 좌표 자동 검색

6. **노인 친화적 UX**: 큰 버튼, 전체 서비스 음성 인식 지원, 접근성 설정
   - 모든 텍스트 입력창에 음성 인식 기능 탑재
   - 키보드 타이핑 어려운 노인도 쉽게 사용

7. **보호자 권한**: 자녀가 부모님 데이터 관리 가능

이 MVP는 이미 **AI 능동형 케어의 기본 기능을 구현**하여 차별화된 서비스를 제공하고 있으며,

향후 시간대별 자동 알림 푸시, 도착 확인, 하루 흐름 관리, AI 리포트 등을 단계적으로 확장하여

원래 비전인 "하루 전체를 관리하는 AI 비서"와 "패밀리 케어 서비스"로 발전시킬 예정이다.
